## 👋 About Me

I'm **Sam**, an **AI Developer, Data Science Developer, and MLOps Engineer**. I don't just train models in a notebook and call it done — I build the entire road from a messy CSV to a system that's actually serving predictions in production, monitored, versioned, and reproducible.

```
Data  →  Models  →  ML Pipelines  →  MLOps  →  Deployment  →  Production AI Systems
```

That pipeline above is basically my job description. I spend my time moving left-to-right through it: cleaning and exploring data, building and evaluating models, wrapping them in reproducible pipelines, and shipping them behind CI/CD so they survive contact with the real world.

- 🔭 Currently building end-to-end **ML pipelines** with tracked experiments, versioned data, and automated deployment
- 🧠 Deep interest in **Computer Vision** and **NLP**, from classical approaches to modern deep learning
- ⚙️ Obsessed with the "ops" in MLOps — reproducibility, CI/CD, and models that don't break in production
- 🌱 Always learning — new architectures, new tooling, new ways to make pipelines less fragile
- 💬 Happy to talk about model deployment, experiment tracking, or why your training run isn't reproducible

## 📊 Data Science

My models are only as good as the data pipeline feeding them. I spend real time on:

- **Exploratory Data Analysis** — understanding distributions, outliers, and relationships before touching a model
- **Data Wrangling** — cleaning, transforming, and structuring raw data with Pandas & NumPy
- **Statistical Analysis** — hypothesis testing, correlation analysis, and validating assumptions
- **Data Visualization** — communicating findings clearly, not just producing charts
- **Feature Engineering** — building the features that actually move model performance

## ⚙️ MLOps

This is where models stop being notebooks and start being systems.

| Area | What I Do |
